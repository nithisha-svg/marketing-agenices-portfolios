# Foldwise — React version

The Foldwise "AI product designer" leporello site, rebuilt as a React app with
[Vite](https://vitejs.dev). A book of 12 panels (cover, contents, seven case
studies, field notes, about, contact) that unfolds panel by panel as you
scroll — alternating fold direction, with shading from the fold angle and the
opening crease kept centred.

## Run it

```bash
npm install
npm run dev        # dev server at http://localhost:5173
```

```bash
npm run build      # production build into dist/
npm run preview    # serve the production build
```

## Structure

```
index.html                 document shell + Google Fonts
src/
  main.jsx                 React entry
  App.jsx                  top-level: bar, drawer, fold, goto context
  styles.css               the full stylesheet (unchanged from the original)
  data.js                  WORKS / NOTES / address / vCard content
  art.js                   the seven 400x300 SVG plates + QR mark, built as strings
  goto.js                  the goto(id) context shared by nav links and panels
  components/
    Bar.jsx                fixed top bar
    Drawer.jsx             phone menu drawer
    Fold.jsx               the fold engine: scroll -> 3D transforms via refs
    panels.jsx             Cover, Contents, WorkPanel, Notes, About, Contact
```

## How the React version maps to the original

- **Content**: `WORKS` and `NOTES` in `src/data.js`. Each work's `art` key is
  a function in `ART` (`src/art.js`) returning one 400x300 SVG plate. Add a
  case study by adding to both.
- **The fold**: panels are React components, but their transforms are driven
  imperatively in `Fold.jsx` (refs + `requestAnimationFrame`) so the scroll
  animation stays at 60fps. The strip is (N - 1) x 62% of a screen tall per
  panel; change the `0.62` in `setup()` for a slower or faster unfold.
- **Panels** are drawn at 440x600 and scaled by `--k` so the whole book fits
  the window.
- Under **560px** the book lies flat as a vertical stack; under
  `prefers-reduced-motion` it lies flat as a sideways snap scroller with the
  SVG animations paused.
- **Arrow keys** step panel by panel on desktop; a case-study panel opens
  with a click, Enter or Space.
- The SVG plates are injected with `dangerouslySetInnerHTML`. They are static
  strings generated by our own code (`src/art.js`), so this is safe — but if
  you ever feed them external content, sanitize it first.

## Before shipping

Fictional brand ("Foldwise"), fictional clients ("Tessel", "Kompas"); every
case study, vendor, figure and note is invented, and the address uses the
reserved `.example` domain (`hello@foldwise.example`). Replace all of it in
`src/data.js` before going live.

# ZYVO — Creative Digital Growth Studio

A complete React website for ZYVO, a creative digital growth agency, redesigned in a light editorial system: warm off-white canvas, black ink, coral/peach accents, Inter Tight typography, pill buttons, rounded section shells, and scroll reveals.

## Tech stack

- **React 18** + **Vite 5**
- **React Router 6** for page routing
- **Tailwind CSS 3** for layout utilities
- **Lucide React** for small interface icons
- Custom CSS design system in `src/index.css`

## Getting started

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

### Production build

```bash
npm run build
npm run preview
```

The production build is written to `dist/`.

## Routes

| Route | Page |
| --- | --- |
| `/` | Home |
| `/about` | About |
| `/services` | Services index |
| `/services/:slug` | Service detail |
| `/work` | Work / case study index |
| `/work/:slug` | Case study detail |
| `/contact` | Contact + project enquiry form |
| `*` | 404 |

## Design system

The main tokens live at the top of `src/index.css`:

- Background `#f5f7fa`, ink `#000`, dark `#141414`
- Coral `#ec5a4f`, peach `#f79276`, forest green `#16854a`
- Soft blue `#dbe3f6`, cream `#f8f1ee`
- Easing `cubic-bezier(.22,.8,.24,1)`
- Type: **Inter Tight** (300–600), **Montserrat** 600 for select card details

Reusable classes include `.t-hero`, `.t-h2`…`.t-h6`, `.pill-btn`, `.eyebrow`, `.rv` (reveal), `.surface`, `.round-bottom`, `.dark-shell`, `.photo`, `.faq-item`, `.plan-card`, and `.site-footer`.

## Notes

- All imagery uses remote Unsplash URLs. Replace them with licensed assets before production.
- The contact form and footer newsletter are front-end demos: the contact form prepares/copies an enquiry or opens the user's email app; the newsletter shows a confirmation state.
- The site is responsive at 1299.98px, 1023.98px, and 809.98px, with reduced-motion support.
- The 404 page, work filters, service reel, FAQ accordion, testimonials, benefits scroller, and article modal are all interactive.
